===============
Modeling Basics
===============

When you create a new table—like ``BlogPost`` or ``Author``—you almost always want an ``id`` column and ``created_at`` / ``updated_at`` timestamps. Instead of copying those columns onto every model, inherit from one of Advanced Alchemy's base classes.

Choosing a Base Class
---------------------

Pick the base class that matches how you want row IDs generated. Every ``*Base`` class also has an ``*AuditBase`` twin that adds automatic ``created_at`` and ``updated_at`` UTC timestamps:

.. list-table::
   :header-rows: 1
   :widths: 34 66

   * - Base Class
     - Best When You Want
   * - ``UUIDv7Base`` / ``UUIDv7AuditBase``
     - Time-sorted UUID primary keys that index well and stay safe to expose in URLs.
   * - ``UUIDBase`` / ``UUIDAuditBase``
     - Random UUIDv4 primary keys.
   * - ``BigIntBase`` / ``BigIntAuditBase``
     - Auto-incrementing 64-bit integer IDs (``1, 2, 3...``) that also work in SQLite tests.
   * - ``IdentityBase`` / ``IdentityAuditBase``
     - SQL standard ``GENERATED BY DEFAULT AS IDENTITY`` integer primary keys.
   * - ``NanoIDBase`` / ``NanoIDAuditBase``
     - Short, URL-friendly string IDs.
   * - ``DefaultBase``
     - A clean blank slate when you want to define your own primary key or composite key.

Here is a blog post table with an auto-incrementing integer ID and automatic ``created_at`` / ``updated_at`` columns:

.. code-block:: python

    import datetime
    from typing import Optional
    from sqlalchemy.orm import Mapped, mapped_column
    from advanced_alchemy.base import BigIntAuditBase


    class BasicBlogPost(BigIntAuditBase):
        __tablename__ = "basic_blog_post"

        title: Mapped[str] = mapped_column(index=True)
        content: Mapped[str]
        published: Mapped[bool] = mapped_column(default=False)
        published_at: Mapped[Optional[datetime.datetime]] = mapped_column(default=None)

.. tip::

    Base classes and mixins automatically keep your physical table columns tidy: ``id`` comes first, your custom columns sit in the middle, and audit timestamps sit at the end.

.. _many_to_many_relationships:

Many-to-Many Relationships
--------------------------

Suppose one blog post can have several topics, and one topic belongs to many posts. Join them with a link table attached to ``orm_registry.metadata``, and mix in ``SlugKey`` to give each topic a URL-friendly ``slug`` column:

.. code-block:: python

    from sqlalchemy import Column, ForeignKey, Table
    from sqlalchemy.orm import Mapped, mapped_column, relationship
    from advanced_alchemy.base import BigIntAuditBase, orm_registry
    from advanced_alchemy.mixins import SlugKey

    blog_post_topic = Table(
        "blog_post_topic",
        orm_registry.metadata,
        Column("post_id", ForeignKey("tagged_blog_post.id", ondelete="CASCADE"), primary_key=True),
        Column("topic_id", ForeignKey("blog_topic.id", ondelete="CASCADE"), primary_key=True),
    )


    class TaggedBlogPost(BigIntAuditBase):
        __tablename__ = "tagged_blog_post"

        title: Mapped[str] = mapped_column(index=True)
        topics: Mapped[list["BlogTopic"]] = relationship(
            secondary=blog_post_topic,
            back_populates="posts",
            lazy="selectin",
        )


    class BlogTopic(BigIntAuditBase, SlugKey):
        __tablename__ = "blog_topic"

        name: Mapped[str] = mapped_column(unique=True, index=True)
        posts: Mapped[list["TaggedBlogPost"]] = relationship(
            secondary=blog_post_topic,
            back_populates="topics",
            lazy="selectin",
        )

.. _using_unique_mixin:

Preventing Duplicate Rows
-------------------------

When users tag a post with ``"Python"`` and ``"python"``, you usually want both to point to the same tag row instead of crashing with a duplicate-key error. Mix in ``UniqueMixin`` and tell it how to recognize an existing record:

.. code-block:: python

    from typing import Hashable, Optional
    from sqlalchemy.orm import Mapped, mapped_column
    from sqlalchemy.sql.elements import ColumnElement
    from advanced_alchemy.base import BigIntAuditBase
    from advanced_alchemy.mixins import SlugKey, UniqueMixin
    from advanced_alchemy.utils.text import slugify


    class UniqueTopic(BigIntAuditBase, SlugKey, UniqueMixin):
        __tablename__ = "unique_topic"

        name: Mapped[str] = mapped_column(unique=True, index=True)

        @classmethod
        def unique_hash(cls, name: str, slug: Optional[str] = None) -> Hashable:
            del slug
            return slugify(name)

        @classmethod
        def unique_filter(cls, name: str, slug: Optional[str] = None) -> ColumnElement[bool]:
            del slug
            return cls.slug == slugify(name)

.. _custom_primary_keys:

Custom Keys and Dataclass Models
--------------------------------

Need to supply your own primary key (such as an external SKU code) or prefer Python dataclass syntax? Combine ``DefaultBase`` with ``AuditColumns`` or SQLAlchemy's ``MappedAsDataclass``:

.. tab-set::

    .. tab-item:: Custom Primary Key

        .. code-block:: python

            from sqlalchemy.orm import Mapped, mapped_column
            from advanced_alchemy.base import DefaultBase
            from advanced_alchemy.mixins import AuditColumns


            class ImportedProduct(DefaultBase, AuditColumns):
                __tablename__ = "imported_product"

                id: Mapped[str] = mapped_column(primary_key=True)
                name: Mapped[str]

    .. tab-item:: Dataclass Model

        .. code-block:: python

            from typing import Optional
            from sqlalchemy.orm import Mapped, MappedAsDataclass, mapped_column
            from advanced_alchemy.base import DefaultBase


            class DataclassAuthor(MappedAsDataclass, DefaultBase):
                __tablename__ = "dataclass_author"

                id: Mapped[int] = mapped_column(primary_key=True, init=False)
                name: Mapped[str]
                bio: Mapped[Optional[str]] = mapped_column(default=None)

See :doc:`/reference/base` and :doc:`/reference/mixins/index` for the full list of base classes and mixins.

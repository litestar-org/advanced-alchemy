===============
Modeling Basics
===============

Advanced Alchemy extends SQLAlchemy 2.0's declarative mapping with opinionated base classes, composable primary-key and audit mixins, and deterministic physical column ordering.

Declarative Base Classes
------------------------

Choose an opinionated base class when you want a pre-configured primary key and optional ``created_at`` / ``updated_at`` audit timestamps, or start from :class:`~advanced_alchemy.base.DefaultBase` when you need custom primary keys:

.. list-table:: Declarative Base Classes
   :header-rows: 1
   :widths: 28 72

   * - Base Class
     - Description
   * - :class:`~advanced_alchemy.base.AdvancedDeclarativeBase`
     - Low-level registry-aware base for custom declarative hierarchies.
   * - :class:`~advanced_alchemy.base.DefaultBase`
     - Automatic snake_case table naming and bind-aware metadata without a predefined primary key.
   * - :class:`~advanced_alchemy.base.BigIntBase` / :class:`~advanced_alchemy.base.BigIntAuditBase`
     - ``BIGINT`` sequence/auto-increment primary key (with optional audit columns).
   * - :class:`~advanced_alchemy.base.IdentityBase` / :class:`~advanced_alchemy.base.IdentityAuditBase`
     - SQL standard ``GENERATED BY DEFAULT AS IDENTITY`` primary key (with optional audit columns).
   * - :class:`~advanced_alchemy.base.UUIDBase` / :class:`~advanced_alchemy.base.UUIDAuditBase`
     - UUIDv4 primary key (with optional audit columns).
   * - :class:`~advanced_alchemy.base.UUIDv6Base` / :class:`~advanced_alchemy.base.UUIDv6AuditBase`
     - Time-ordered UUIDv6 primary key (with optional audit columns).
   * - :class:`~advanced_alchemy.base.UUIDv7Base` / :class:`~advanced_alchemy.base.UUIDv7AuditBase`
     - Monotonic RFC 9562 UUIDv7 primary key (with optional audit columns).
   * - :class:`~advanced_alchemy.base.NanoIDBase` / :class:`~advanced_alchemy.base.NanoIDAuditBase`
     - URL-friendly NanoID primary key (with optional audit columns).

Composable Mixins and Column Ordering
-------------------------------------

Mixins in :mod:`advanced_alchemy.mixins` (:class:`~advanced_alchemy.mixins.UUIDPrimaryKey`, :class:`~advanced_alchemy.mixins.UUIDv7PrimaryKey`, :class:`~advanced_alchemy.mixins.BigIntPrimaryKey`, :class:`~advanced_alchemy.mixins.IdentityPrimaryKey`, :class:`~advanced_alchemy.mixins.NanoIDPrimaryKey`, :class:`~advanced_alchemy.mixins.AuditColumns`, :class:`~advanced_alchemy.mixins.SlugKey`, :class:`~advanced_alchemy.mixins.SentinelMixin`, and :class:`~advanced_alchemy.mixins.UniqueMixin`) assign explicit ``sort_order`` values so newly created tables place ``id`` first (``-100``), user columns in the middle (``0``), and ``sa_orm_sentinel`` / ``created_at`` / ``updated_at`` at the end (``3001``–``3003``):

.. code-block:: python

    import datetime
    from typing import Optional
    from sqlalchemy.orm import Mapped, mapped_column
    from advanced_alchemy.base import BigIntAuditBase


    class BasicBlogPost(BigIntAuditBase):
        __tablename__ = "basic_blog_post"

        title: Mapped[str] = mapped_column(index=True)
        content: Mapped[str]
        published: Mapped[bool] = mapped_column(default=False)
        published_at: Mapped[Optional[datetime.datetime]] = mapped_column(default=None)

Many-to-Many Relationships
--------------------------

Use ``orm_registry.metadata`` when defining association tables alongside declarative models:

.. code-block:: python

    from sqlalchemy import Column, ForeignKey, Table
    from sqlalchemy.orm import Mapped, mapped_column, relationship
    from advanced_alchemy.base import BigIntAuditBase, orm_registry
    from advanced_alchemy.mixins import SlugKey

    blog_post_topic = Table(
        "blog_post_topic",
        orm_registry.metadata,
        Column("post_id", ForeignKey("tagged_blog_post.id", ondelete="CASCADE"), primary_key=True),
        Column("topic_id", ForeignKey("blog_topic.id", ondelete="CASCADE"), primary_key=True),
    )


    class TaggedBlogPost(BigIntAuditBase):
        __tablename__ = "tagged_blog_post"

        title: Mapped[str] = mapped_column(index=True)
        topics: Mapped[list["BlogTopic"]] = relationship(
            secondary=blog_post_topic,
            back_populates="posts",
            lazy="selectin",
        )


    class BlogTopic(BigIntAuditBase, SlugKey):
        __tablename__ = "blog_topic"

        name: Mapped[str] = mapped_column(unique=True, index=True)
        posts: Mapped[list["TaggedBlogPost"]] = relationship(
            secondary=blog_post_topic,
            back_populates="topics",
            lazy="selectin",
        )

.. _using_unique_mixin:

Using UniqueMixin
-----------------

:class:`~advanced_alchemy.mixins.UniqueMixin` deduplicates records inside the current session and database via ``as_unique_async`` and ``as_unique_sync``:

.. code-block:: python

    from typing import Hashable, Optional
    from sqlalchemy.orm import Mapped, mapped_column
    from sqlalchemy.sql.elements import ColumnElement
    from advanced_alchemy.base import BigIntAuditBase
    from advanced_alchemy.mixins import SlugKey, UniqueMixin
    from advanced_alchemy.utils.text import slugify


    class UniqueTopic(BigIntAuditBase, SlugKey, UniqueMixin):
        __tablename__ = "unique_topic"

        name: Mapped[str] = mapped_column(unique=True, index=True)

        @classmethod
        def unique_hash(cls, name: str, slug: Optional[str] = None) -> Hashable:
            del slug
            return slugify(name)

        @classmethod
        def unique_filter(cls, name: str, slug: Optional[str] = None) -> ColumnElement[bool]:
            del slug
            return cls.slug == slugify(name)

Using MappedAsDataclass
-----------------------

Combine :class:`~sqlalchemy.orm.MappedAsDataclass` with :class:`~advanced_alchemy.base.DefaultBase` when you want dataclass-style ``__init__`` generation:

.. code-block:: python

    from typing import Optional
    from sqlalchemy.orm import Mapped, MappedAsDataclass, mapped_column
    from advanced_alchemy.base import DefaultBase


    class DataclassAuthor(MappedAsDataclass, DefaultBase):
        __tablename__ = "dataclass_author"

        id: Mapped[int] = mapped_column(primary_key=True, init=False)
        name: Mapped[str]
        bio: Mapped[Optional[str]] = mapped_column(default=None)

.. _custom_primary_keys:

Caller-Supplied Primary Keys with Audit Columns
-----------------------------------------------

When importing records that carry caller-supplied primary keys, combine :class:`~advanced_alchemy.base.DefaultBase` with :class:`~advanced_alchemy.mixins.AuditColumns`:

.. code-block:: python

    from sqlalchemy.orm import Mapped, mapped_column
    from advanced_alchemy.base import DefaultBase
    from advanced_alchemy.mixins import AuditColumns


    class ImportedProduct(DefaultBase, AuditColumns):
        __tablename__ = "imported_product"

        id: Mapped[str] = mapped_column(primary_key=True)
        name: Mapped[str]
